# vheyAI

Vhey is a React, Aptos, and Shelby Protocol dapp for generating refraction-style artwork, storing blobs on Shelby, and minting the saved artwork on Shelbynet.

## Development

```bash
npm install
npm run dev
```

Create a local `.env` from `.env.example` and set `VITE_SHELBY_API_KEY`. Do not commit real environment values.

## Checks

```bash
npm run lint
npm run build
```
